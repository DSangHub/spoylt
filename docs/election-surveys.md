# Election surveys

The blue Surveys button opens four races: Texas Governor, Ohio Governor, Ohio U.S. Senate, and Texas U.S. Senate. All four include seven candidate choices (including declared write-ins) and an undecided option. Ohio governor choices include the lieutenant governor ticket. Candidate lists were checked against the linked official certification documents on October 23, 2026.

Definitions and responses are held in the unexposed `survey_private` schema. Browser roles have no direct table access. Public `get_election_surveys` returns candidate definitions, aggregate counts, and only the caller's own choice. `answer_election_survey` requires a confirmed, non-anonymous, unbanned account and validates the choice against the requested open race. A primary key enforces one response per account per race; updating changes the existing response. There is no client supplied user ID. Surveys close November 4, 2026 at 08:00 UTC.

The page explains that selections are linked to accounts, only totals are public, and participation does not verify registration or residence. Results are voluntary survey responses, not scientific polls or official election results. Individual responses must not be exported or displayed publicly.

## Candidate check marks and moderated comments

The single candidate choice uses a visible check mark while retaining accessible radio semantics. Each race has an optional 1,000-character public comment field. Members must consent to public posting and transmission of comment text to OpenAI. Their private survey selection is not attached to the public comment. Approved comments are attributed as “SPOYLT member”; users see their own comments marked “Your comment.” The latest 50 approved comments per race are displayed as text, never HTML.

`moderate-survey-comment` authenticates the user and submits the canonical text through `prepare_election_survey_comment`. Comments are private while pending or rejected. Saving a survey choice is required first. Confirmed, non-anonymous accounts may submit up to five comments per hour; identical recently approved comments are not reposted. The Community Firewall checks prohibited text before provider calls. OpenAI's moderation endpoint and a strict viewpoint-neutral civility policy must both allow the text before the service-only completion function can approve it. Provider errors, missing credentials, malformed decisions and timeouts leave the submission hidden. Browsers cannot bypass screening, directly read the comments table, approve comments, or change rejected text into an approved post. The server rechecks account status, the open race and local firewall before publication. No automatic emails are sent by survey comments.
